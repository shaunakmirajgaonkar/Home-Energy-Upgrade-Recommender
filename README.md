# Home Energy Upgrade Recommender

A 100% local-first Streamlit dashboard for screening practical home energy upgrades from bills, climate, building conditions, equipment efficiency, and household context.

## Features
- Explainable 0–100 upgrade-priority screening
- Low / Moderate / High / Critical classes
- Upgrade recommendations for insulation, windows, HVAC, appliances, ventilation and heat management
- Utility bill trend analytics
- Zone benchmarking
- Interactive scenario lab
- Local CSV upload, validation, filtering and export
- No external APIs

This is decision-support screening, not an engineering audit or guaranteed savings calculator.
